# Mapping class groups

Reading notes and feature plans for mapping class groups, surface homeomorphisms, Dehn twists, Nielsen–Thurston theory, train tracks, and mapping tori.

Start with [`books/README.md`](books/README.md). It currently connects Farb–Margalit, geometric group theory, and Peter Scott’s 3-manifold geometries.

## Status

This repository currently contains references and research notes. It does not yet contain a mapping-class-group visualizer or a general-purpose implementation.

Source links should point to authors, publishers, journals, DOI records, or other legitimate public hosts. Do not add copyrighted book or paper scans without clear permission.
